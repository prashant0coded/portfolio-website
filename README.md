# Portfolio

    npm install
    npm run dev      # local preview
    npm run build    # production build in dist/

Edit your text in `src/content.js`. Before deploying, replace `https://example.com` in
`index.html`, `public/robots.txt` and `public/sitemap.xml` with your real domain,
and add `sameAs` links to the JSON-LD block in `index.html` once you have profile URLs.
